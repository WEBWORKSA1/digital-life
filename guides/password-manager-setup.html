Set up a password manager in one evening

Reused passwords are how one company’s breach becomes your problem on ten other sites. A password manager ends reuse without asking you to remember anything new except one passphrase.

Reviewed November 2026 · 6 minute read

What a password manager does

It is an encrypted vault that creates a long random password for every account, stores it and fills it in for you. You unlock the vault with a single master passphrase, plus a fingerprint or face on your phone. Because each password is unique, a leak at one service cannot be used anywhere else.

Step 1: Pick one and commit

You have three sound routes: the manager built into your phone or browser ecosystem, a dedicated cross-platform manager, or an open-source one. What matters more than brand is that it works on every device you use, supports two-step login for the vault itself and has a published, independent security audit. Choose one tonight; a good manager in use beats a perfect one you are still researching.

Step 2: Create a master passphrase

This is the one secret you must remember, so make it long and random. Six random words is a solid baseline. Use our passphrase generator, write the result on paper and keep the paper somewhere safe until it is memorised.

Step 3: Import what you already have

Most browsers can export saved passwords to a file that your manager imports in one step. Delete the export file afterwards and empty the recycle bin, because it contains every password in plain text. Then switch off the browser’s own password saving so there is one source of truth.

Step 4: Fix the accounts that matter first

Do not try to change 200 passwords tonight. Change these, in order, letting the manager generate each new one:

  1. Your main email account
  2. Banking and payment services
  3. Your phone and cloud account
  4. Shopping sites that store a card
  5. Social media

For everything else, change the password the next time you log in. Most managers include a report of reused and breached passwords; work through it a few at a time.

Step 5: Plan for being locked out

Save the manager’s recovery kit or emergency codes offline. If it offers emergency access, nominate someone you trust. Add two-step login to the vault.

Do it now: test your current main password in the strength checker, then generate a master passphrase.

Common worries

Is it risky to keep everything in one place? The vault is encrypted with a key derived from your passphrase, which the provider does not hold. That concentrated, well-protected risk is far smaller than the spread-out risk of reuse.

What about passkeys? Use them where offered. Managers store passkeys alongside passwords, so the two work together. See two-step login and passkeys, explained.
