Password strength checker

Your password is checked on this page by your own device. It is never sent, stored or logged.

What the result means

Strength is measured in bits of entropy: each extra bit doubles the number of guesses an attacker needs. We estimate it from length and the kinds of characters used, then reduce it for patterns attackers try first, such as common words, sequences, repeats and years.

The crack time assumes an attacker who has stolen a database and can try ten billion guesses a second on their own hardware. Online logins are far slower to attack, but leaked databases are where most password cracking happens.

What actually makes a password strong

  • Length beats complexity. Sixteen lowercase letters chosen at random are stronger than eight characters with symbols.
  • Randomness matters more than cleverness. Substituting 0 for o is in every cracking dictionary.
  • Uniqueness is non-negotiable. The strongest password is worthless once it leaks from another site where you reused it.

The practical answer is a password manager that generates a different random password for each account, protected by one long passphrase. Try the passphrase generator and read how to set up a password manager.

This estimate is a guide. A high score does not make a reused or already leaked password safe.
